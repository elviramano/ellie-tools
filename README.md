# ellie-tools

Practical tools and automations built with Codex. Each tool has its own folder, installation instructions, and tests.

| Tool | What it does | Platform |
|---|---|---|
| [YouTube Transcripts](youtube-transcripts/) | Save a video's available English or Russian captions as readable Markdown, with timestamps, metadata, and duplicate protection. | macOS |

Start with the tool's README. This repository contains source code and documentation; it does not include user transcripts, private settings, or credentials.

## Contributing

Open an issue for a bug or a focused pull request for an improvement. Include reproduction steps and run the affected tool's tests. Do not attach private transcripts, cookies, credentials, or personal filesystem paths to public reports. Network-dependent behavior should be checked locally; automated tests use synthetic data.
